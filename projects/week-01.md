# Week 1 project briefs

Pick one per project day. Stay inside W1.1–W1.4.

## PW1.A — Unit converter (day 1–2)

Read two integers from the command line: a value and a mode (`1` = C to F, `2` = F to C). Print the result as an integer (truncate). No floats required if you use integer arithmetic you can explain.

Unlocks used: argv, `if`, integer math.

## PW1.B — Times table (day 3–4)

Print an n×n multiplication table for `n` given as `argv[1]` (2 ≤ n ≤ 12). Align columns as best you can with spaces.

## PW1.C — Guess a number (day 5–6)

Program picks a compile-time constant (e.g. 7). User types guesses in a loop until correct. Print "low" / "high" / "ok".

Do not add random number generation unless W1.x covers it and the tutor unlocked it.
