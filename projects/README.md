# Daily project

1–2 hours. You own the program. The tutor may **cut scope**, not write the implementation.

**Rule:** only skills that are mastered or currently unlocking. If you want sockets in week 2, you do not add sockets — you add a node and drill it first.

Finish a small complete program. Prefer throwaway or kata-keep over a 6-week unfinished "OS".

Afterward, note in STATE: what compiled, what the sanitizer said, what you still cannot explain.
