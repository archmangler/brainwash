# Unassisted daily puzzle

One problem per day. **No AI, no notes if you can manage it.** Time-box 25–40 minutes.

Log in `learner/STATE.md`:

- `unaided` — solved in the box
- `extra time` — solved after the box, still no AI
- `failed` — stop. Debrief in the **next** drill, not tonight

Puzzles are tagged to unlocked or just-unlocking nodes. Do not pick random contest graphs.
