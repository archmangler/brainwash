# P1.1 — Fizz (unassisted)

**Nodes:** W1.3 (ok to attempt once W1.1 is unlocking and you have written a loop in the drill).

Write a program `fizz.c` that prints integers from 1 to 30 inclusive, one per line.

- If the number is divisible by 3, print `Fizz` instead of the number.
- If divisible by 5, print `Buzz` instead of the number.
- If divisible by both, print `FizzBuzz`.

No AI. 25–40 minutes. Compile with:

```bash
gcc -Wall -Wextra -Werror -std=c11 -g -O0 -o fizz fizz.c
./fizz
```

Put your file anywhere you like (e.g. `puzzles/work/fizz.c` — that directory is gitignored).
