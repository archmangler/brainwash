# P1.2 — Count digits (unassisted)

**Nodes:** W1.2, W1.3

Write `int digit_count(int n)` that returns how many decimal digits `n` has.

- `0` has 1 digit.
- Negative numbers: count digits of the magnitude (`-17` → 2).

Include a `main` that checks a few cases and prints `ok` or `fail`.

No AI. Time-box 25–40 minutes.
